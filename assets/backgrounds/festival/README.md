# Festival artwork

General festival and utsav scenes. Use when an event-specific image is useful but no deity-specific folder applies.

Add text-free JPG, JPEG, PNG or WebP images here. Recommended portrait size: 1080 × 1920 (9:16). Keep the main subject clear of the top and bottom caption-safe areas. Do not include dates, Panchang timings, subtitles, logos or generated lettering; the video renderer adds all text separately.
